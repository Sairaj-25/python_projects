 #  NATO Alphabet Start (CLI)

A simple command-line application that converts user-input words into their corresponding NATO phonetic alphabet code words.

This project demonstrates modern Python practices including `pathlib`, `pandas`, dictionary comprehension, list comprehension, and exception handling.

---

##  Project Overview

The NATO Phonetic Alphabet is used to ensure clear communication over radio and telephone by assigning code words to each letter of the alphabet.

Example:

| Letter | Code Word |
|--------|----------|
| A      | Alfa     |
| B      | Bravo    |
| C      | Charlie  |

This application:
- Reads phonetic data from a CSV file
- Converts it into a dictionary
- Accepts user input
- Outputs the phonetic translation
- Handles invalid inputs gracefully
