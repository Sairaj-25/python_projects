#  Weather Forecast Rain Alert App

A clean and simple Python application that checks whether it will rain in the next few hours using the OpenWeatherMap 5-Day Forecast API.

This project demonstrates:

- API integration using `requests`
- Secure API key management using environment variables
- JSON parsing and conditional logic
- Clean and beginner-friendly Python scripting

---

##  Features

- Fetches 5-day / 3-hour interval forecast data
- Detects rain using weather condition codes
- Displays location-based forecast
- Uses metric units (°C)
- Easily configurable for 3-hour or 24-hour checks

---

## 🛠 Tech Stack

- Python 3.x
- requests
- python-dotenv
- OpenWeatherMap API
