# ☕ Coffee Machine — Python Project

A console-based **Coffee Machine Simulator** built using Python.  
This project mimics a real-world coffee vending machine that allows users to order drinks, process payments, check resources, and generate reports.

It is designed to practice core Python concepts such as:
- Functions
- Conditionals
- Loops
- Dictionaries
- User input handling
- Basic state management

---

## 📌 Project Overview

The Coffee Machine program allows users to:

- ☕ Order drinks (Tea,Coffee, Espresso, Latte, Cappuccino)
- 💰 Insert coins and process payments
- 📊 View current machine resources
- 🔄 Continue ordering until turned off
- 🧾 Track total profit

The program ensures:
- Sufficient ingredients are available
- Payment is valid
- Correct change is returned

## 🧠 Features

✔ Drink selection menu  
✔ Ingredient resource tracking  
✔ Coin-based payment system
